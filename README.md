# Semitexa Music

`semitexa/music`

The default music player for Semitexa OS: a **Music** app with a bundled "Semitexa Ambient" playlist of four original, program-generated tracks (generated by `tools/gen_tracks.py`; no samples or third-party recordings).

## Install

Not included by the installer. Add it to an existing project from the project root:

```bash
docker compose run --rm --no-deps --user "$(id -u):$(id -g)" app composer require semitexa/music
bin/semitexa server:restart
```

It depends on `semitexa/os` (not in the installer's set); Composer installs it with it.

## What it provides

- The `music` assistant skill, which opens the player dialog at `/os/app/music`.
- Four Ogg tracks in `src/Application/Static/audio/`.

No console commands, attributes or tables.
